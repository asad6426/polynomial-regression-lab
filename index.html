Polynomial Regression Lab

Some relationships curve. A car going twice as fast doesn't need twice the distance to stop. It needs far more. This Lab shows why a straight line breaks on curved data, how adding an x² term fixes it, and how the coefficients are worked out by hand.

The fix

Add a squared term

Polynomial regression keeps the straight-line equation and adds powers of x. With degree 2 we add one new term, b₂x², and b₂ controls how much the line bends.

ŷ = b₀ + b₁x + b₂x2

The trick: x² is just a new column

We don't need a new algorithm. We create a new feature, x², and give both columns to ordinary linear regression. The model is still linear in its coefficients b₀, b₁ and b₂, so every least-squares tool still works.

One input column becomes two features.

xx²y

From linear to polynomial: one equation family

Simple linear
y = α₀ + α₁x₁
Multiple linear (m input variables)
y = α₀ + α₁x₁ + α₂x₂ + … + αₘxₘ = α₀ + Σi=1m αᵢxᵢ
Polynomial, degree n (one input x)
y = α₀ + α₁x + α₂x² + … + αₙxⁿ = α₀ + Σj=1n αⱼxj

Look at the power of x. In the linear equations every x has power 1, so they are degree-1 polynomials. Polynomial regression keeps the same equation and adds terms with higher powers.

Notation: books and videos write the coefficients as α (alpha), β (beta), θ (theta) or b. They all mean the same thing. This Lab uses b, so b₀ = α₀, b₁ = α₁, b₂ = α₂.

What each degree looks like

ক্লাসে বলুন: Degree মানে x-এর সবচেয়ে বড় power। Degree 0 মানে x⁰ = 1, তাই y একটা constant, একদম সমতল line। Degree 1 মানে ঢালু line, degree 2 মানে parabola (একটা বাঁক)। এভাবে degree n পর্যন্ত যাওয়া যায়।

ক্লাসে বলুন: Polynomial regression আসলে নতুন কোনো algorithm না। x² নামে একটা নতুন column বানিয়ে linear regression-কেই দিই। তাই একে এখনো "linear" model বলা হয়, কারণ b-গুলোর দিক থেকে সমীকরণটা linear।

The math, by hand

Finding b₀, b₁ and b₂ with the normal equations

Least squares picks the coefficients that make SSE = Σ(y − ŷ)² as small as possible. For degree 2 this gives three equations in three unknowns. We build them, then solve by elimination.

Step 1Write the goal

We want the curve ŷ = b₀ + b₁x + b₂x² that minimises the total squared error. Setting the derivative of SSE with respect to each b to zero gives the normal equations, one for each coefficient:

Σy   = n·b₀  + b₁Σx  + b₂Σx²
Σxy  = b₀Σx  + b₁Σx² + b₂Σx³
Σx²y = b₀Σx² + b₁Σx³ + b₂Σx⁴

Rule: n unknowns need n equations. Degree 2 has 3 coefficients, so it needs 3 equations.

Step 2Build the sums table

Every Σ in those equations comes from one table. Each row is one car test.

xx²x³x⁴yxyx²y

Step 3Plug the sums into the equations

n = 5, Σx = 15, Σx² = 55, Σx³ = 225, Σx⁴ = 979, Σy = 95, Σxy = 380, Σx²y = 1636.

(1)   5b₀ +  15b₁ +  55b₂ =   95
(2)  15b₀ +  55b₁ + 225b₂ =  380
(3)  55b₀ + 225b₁ + 979b₂ = 1636

Step 4Remove b₀ from equation (2)

Multiply (1) by 3 so its b₀ term matches, then subtract it from (2).

(2)     15b₀ + 55b₁ + 225b₂ = 380
3×(1)  15b₀ + 45b₁ + 165b₂ = 285
(A)           10b₁ +  60b₂ =  95

Step 5Remove b₀ from equation (3)

Multiply (1) by 11 (because 5 × 11 = 55), then subtract it from (3).

(3)      55b₀ + 225b₁ + 979b₂ = 1636
11×(1)  55b₀ + 165b₁ + 605b₂ = 1045
(B)             60b₁ + 374b₂ =  591

Step 6Remove b₁ and solve for b₂

Multiply (A) by 6 so its b₁ term matches (B), then subtract.

(B)    60b₁ + 374b₂ = 591
6×(A) 60b₁ + 360b₂ = 570
                 14b₂ =  21  →  b₂ = 21 / 14 = 1.5

Step 7Back-substitute for b₁ and b₀

From (A): 10b₁ + 60(1.5) = 95 → 10b₁ = 5 → b₁ = 0.5
From (1): 5b₀ + 15(0.5) + 55(1.5) = 95 → 5b₀ + 7.5 + 82.5 = 95 → 5b₀ = 5 → b₀ = 1
ŷ = 1 + 0.5x + 1.5x2

ক্লাসে বলুন: Linear regression-এ ২টা unknown (b₀, b₁) ছিল, তাই ২টা equation লেগেছিল। এখানে ৩টা unknown, তাই ৩টা equation। বাকি পদ্ধতি একই: sum-এর table বানাও, equation-এ বসাও, আর elimination দিয়ে সমাধান করো।

Choosing the degree

Too simple, just right, too flexible

A higher degree always fits the training points at least as well. That doesn't make it better. Three new test drives (hollow dots) that the model never saw show which degree actually generalises.

Start from the shape of the data. One bend (U or ∩) means degree 2 is enough, so you don't need x³. An S-shape suggests degree 3. Pick the lowest degree that captures the shape, then confirm it with the test error.

In Python

The same model with scikit-learn

PolynomialFeatures builds the [1, x, x²] columns, and LinearRegression does the rest. Press Run to see the output, which matches the hand calculation.

import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

X = np.array([[1], [2], [3], [4], [5]])   # speed (x 10 km/h)
y = np.array([2, 10, 16, 25, 42])          # stopping distance (m)

lin = LinearRegression().fit(X, y)
print("Linear:     b0 =", round(lin.intercept_, 2), " b1 =", lin.coef_.round(2))
print("Linear R2  =", round(r2_score(y, lin.predict(X)), 3))

poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)             # columns: 1, x, x²
print(X_poly)

model = LinearRegression().fit(X_poly, y)
print("Polynomial: b0 =", round(model.intercept_, 2), " coef =", model.coef_.round(2))
print("Poly R2    =", round(r2_score(y, model.predict(X_poly)), 3))

print("Predict 80 km/h, linear:", lin.predict([[8]]).round(1))
print("Predict 80 km/h, poly:  ", model.predict(poly.transform([[8]])).round(1))

Glossary

TermFormulaMeaning
Polynomial regressionŷ = b₀ + b₁x + b₂x² + …Regression that adds powers of x as extra features so the fitted line can bend.
Degreehighest power of xDegree 1 is a straight line, degree 2 is a parabola, degree 3 is a cubic.
Coefficient b₂—Controls the bend. b₂ > 0 opens upward, b₂ < 0 opens downward, b₂ = 0 gives a straight line.
Residuale = y − ŷThe error for one point. A pattern in residuals means the model is missing structure.
SSEΣ(y − ŷ)²Sum of squared errors. Least squares makes this as small as possible.
R²1 − SSE / SSTShare of variation in y the model explains. A high R² doesn't prove the shape is right.
Normal equationsXᵀX b = XᵀyThe system you solve to get the least-squares coefficients. One equation per coefficient.
Feature transformationx → [1, x, x²]Creating new input columns from existing ones. PolynomialFeatures does this in sklearn.
Degree-0 polynomialy = α₀A constant. Because x⁰ = 1, every x gives the same y.
Polynomial feature functionf(x₁, x₂) → x₁, x₂, x₁², x₂² …The add-on that creates higher-power columns before the linear model is trained.
Interaction termx₁·x₂Two input variables multiplied together. sklearn adds these when there is more than one input.
α, β, θ, bα₀ = b₀ …Different notations for the same coefficients. Books and videos use different letters.
Underfitting—The model is too simple to capture the pattern, so errors are high on both training and test data.
Overfitting—The model is so flexible it fits the noise, so training error is low but test error is high.
Extrapolation—Predicting outside the range of the training data. Polynomials can go badly wrong there.
Summary

Six takeaways

When to use itThe data curves, and the residuals of a straight line show a pattern such as + + − − +.
The modelŷ = b₀ + b₁x + b₂x². b₂ controls the bend.
Still linearx² is just a new feature, and the model is linear in b. Ordinary least squares still works.
The math3 coefficients need 3 normal equations. Build a sums table, then solve by elimination.
Pick the degreeChoose by test error, not training error. Too high a degree overfits.
Careful outside the dataPolynomials can shoot off quickly beyond the range you trained on.
