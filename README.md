# Polynomial Regression Lab

How far does a car need to stop at 80 km/h? This lab shows why a straight line fails on curved data and how an x² term fixes it.

**[Open the live lab](https://asad6426.github.io/polynomial-regression-lab/)**

## What it covers

- Interactive curve shaping and degree selection
- Normal equations for b₀, b₁ and b₂ worked by hand
- Underfitting and overfitting compared
- The same model with scikit-learn
- 12-question quiz, essay prompts and glossary

## Details

- **Audience:** Students who already know linear regression
- **Language:** English
- **Built with:** Plain HTML, CSS and JavaScript, with no build step

## Run it locally

Open `index.html` in a browser.
